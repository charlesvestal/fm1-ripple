# Community patches

These Pd patches are by boochow (MIT, see `LICENSE`). They come from his Heavy examples for Korg's logue SDK, the
NTS-1 mk2 and the drumlogue (github.com/boochow: loguesdk_hvcc_examples, nts1mkii_hvcc_examples,
drumlogue_hvcc_examples). Only their names have changed:

- `chiptune.pd` is `ChipTune.pd` from the logue SDK examples.
- `wavefolder.pd` is `WvFldr.pd` from the logue SDK examples.
- `vocoder.pd` is `7ch-Vocoder.pd` from the NTS-1 mk2 examples.
- `bitcrush.pd` is `BitCrush.pd` from the NTS-1 mk2 examples.
- `vca.pd` is `ChangeVol.pd` from the NTS-1 mk2 examples.
- `chorus.pd` is `StereoChorus.pd` from the NTS-1 mk2 examples.
- `reflect.pd` is `Reflection.pd` from the NTS-1 mk2 examples.
- `freqshift.pd` is `FreqShift.pd` from the NTS-1 mk2 examples.
- `monosynth.pd` is `MonoSynth.pd` from the drumlogue examples.

The build makes them into currents for the disk (`app/build/extra`, attached to each release). To play them, use the
droplets in `examples/pd/`.
